# Mitseri Platform

> Production Infrastructure Platform for PT Mitra Services Infotama (Mitseri)

---

## 📖 Overview

Mitseri Platform adalah repository utama yang digunakan untuk membangun, mengelola, dan memelihara seluruh infrastruktur server perusahaan menggunakan teknologi Open Source.

Repository ini dirancang agar proses instalasi server baru dapat dilakukan secara otomatis, terdokumentasi, aman, dan mudah dipelihara.

---

## 🎯 Goals

- Production Ready
- 100% Open Source
- Security First
- Monitoring First
- Backup First
- Easy Deployment
- Easy Maintenance
- Long Term Support (LTS)

---

## 🖥️ Target Environment

| Item | Value |
|------|-------|
| Operating System | Ubuntu Server LTS |
| Container Engine | Docker Engine |
| Reverse Proxy | Traefik |
| Tunnel | Cloudflare Tunnel |
| Remote Access | Tailscale |
| Monitoring | Grafana + Prometheus + Loki |
| Backup | Local + Google Drive |
| Application | Frappe Framework + HRMS |
