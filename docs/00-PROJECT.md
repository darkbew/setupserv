# Mitseri Platform

## Tentang Proyek

Mitseri Platform adalah platform infrastruktur server yang dibangun untuk mendukung seluruh aplikasi internal PT Mitra Services Infotama (Mitseri).

Platform ini dirancang agar mudah dipasang ulang, mudah dipelihara, aman, terdokumentasi, dan menggunakan teknologi open source.

---

# Tujuan

Membangun satu platform server yang dapat digunakan untuk menjalankan berbagai aplikasi perusahaan seperti:

- Frappe Framework
- ERPNext
- HRMS
- LMS
- Custom Application Mitseri

---

# Prinsip

Project ini memiliki beberapa prinsip utama:

- Open Source
- Security First
- Backup First
- Monitoring First
- Documentation First
- Production Ready
- Easy Maintenance

---

# Infrastruktur

Server Production:

- Ubuntu Server LTS
- Docker Engine
- Docker Compose
- Cloudflare Tunnel
- Tailscale
- Grafana
- Prometheus
- Loki
- Uptime Kuma

---

# Target

Platform ini diharapkan mampu:

- Menjalankan lebih dari 500 user
- Mudah di-upgrade
- Mudah dipindahkan ke server baru
- Memiliki backup otomatis
- Memiliki monitoring lengkap
